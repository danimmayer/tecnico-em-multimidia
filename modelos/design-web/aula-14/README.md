# Aula 14 · Do pedido ao plano

Abra `index.html` no navegador: oficina sem cadastro, dependências ou instalação.
Seis missões, uma ficha por dupla, rascunho individual em papel. Cliente e
referências são fictícios; a pesquisa livre não é requisito. A comparação local
introduz pesquisa secundária; os cartões simulam uma entrevista de cliente.

Salvar projeto baixa `briefing-fatia.json`, reaberto em Abrir projeto. Baixar
resumo gera `briefing-fatia.txt`. O rascunho no navegador é conveniência;
não substitui os arquivos. Nada é enviado ao professor. Em computador compartilhado,
confira se há rascunho de outra dupla antes de começar.

Horário: 19:00–22:10; intervalo 19:45–20:05. Fonte do roteiro em
`scripts/lessons/design-web-14.mjs`; regenerar os dados com
`node scripts/build-design-web-14.mjs`. A oficina é HTML autoral, sem etapa de build.
