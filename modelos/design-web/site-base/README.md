# Projeto inicial · Design Web

**Prof. Daniel Marcos Mayer · Técnico em Multimídia**

Este projeto apresenta uma mostra fictícia de trabalhos da turma. O conteúdo
concreto permite avaliar hierarquia, responsividade e navegação antes das
alterações.

Recursos presentes:

- HTML semântico;
- CSS mobile first com alternativas para navegadores antigos;
- grid responsivo;
- foco visível e link para pular conteúdo;
- alternância de tema em JavaScript;
- formulário demonstrativo sem envio de dados.

## Fluxo que adoto em sala

1. duplico a pasta para cada equipe;
2. abro `index.html` e confiro a versão original;
3. altero primeiro conteúdo e identidade;
4. ajusto componentes e responsividade depois;
5. salvo, atualizo e confiro a cada mudança.

## Aplicação por aula

- Aulas 03–05: conteúdo e estrutura de `index.html`;
- Aulas 06–09: cores, tipografia, espaçamento, grid e responsividade em
  `styles.css`;
- Aula 11: eventos e mudança da classe `dark-theme` em `script.js`;
- Aula 13: checklist de acessibilidade;
- Aulas 27–28: adaptação ao projeto final e publicação.

Os projetos publicados usam persona fictícia. Nome completo, foto pessoal,
telefone, localização e rotina de estudantes não entram no conteúdo.

O formulário demonstra interação local. Não há envio de dados sem integração
com um serviço de back-end.
